# Suiyan Visual Design

## 1. 项目定位

项目名称：碎言号（Suiyan）
网站：https://suiyan.cc/
技术栈：Astro

设计方向：
- Modern Minimalism
- Editorial Typography
- Premium Personal Blog
- Clean and Timeless

## 2. 核心约束

本 Skill 只负责视觉优化。

必须遵守：

1. 保留现有页面布局和信息架构。
2. 不随意增加、删除或移动页面模块。
3. 不改变文章数据、Markdown 内容和 URL。
4. 不改变现有路由、SEO 元信息和功能逻辑。
5. 不随意更换 Astro 技术架构。
6. 不引入不必要的 JavaScript 框架。
7. 优先使用现有 CSS 和 Astro 组件。
8. 修改前检查现有实现，避免重复造轮子。
9. 不允许未经确认的大规模 DOM 结构重构。

## 3. 视觉规范

颜色：
- 暖白作为主要背景。
- 墨黑作为主要文字。
- 中性灰作为辅助文字。
- 低饱和度强调色。
- 颜色统一使用 CSS Variables。

字体：
- 优先考虑高品质中文字体。
- 中英文字体需要协调。
- 标题、正文、代码使用合理的字体层级。
- 优先使用本地系统字体或经过许可的字体文件。

排版：
- 强调标题层级。
- 控制正文阅读宽度。
- 提高行高和段落间距。
- 优化中英文混排。
- 避免过度拥挤。

视觉细节：
- 使用克制的边框和分隔线。
- 减少不必要的阴影。
- 避免过度圆角。
- 不滥用渐变和玻璃拟态。
- 保持图标风格一致。
- Hover 状态应当细腻、自然。

## 4. Astro 开发规范

- 遵循现有 Astro 组件结构。
- 优先使用原生 CSS。
- 保持样式作用域合理。
- 不为纯视觉效果引入大型依赖。
- 避免不必要的客户端 Hydration。
- 不破坏静态生成能力。
- 保持图片尺寸稳定，减少布局偏移。

## 5. 工作流程

修改前：
- 检查当前组件和样式。
- 确定修改范围。
- 保存原始页面截图。
- 识别潜在功能风险。

修改中：
- 优先调整设计变量。
- 优先使用现有组件。
- 每次修改保持范围明确。
- 不进行无关重构。

修改后：
- 检查构建结果。
- 检查桌面端和移动端。
- 对比修改前后的页面截图。
- 检查链接、导航和交互。
- 确认原有布局和功能未受破坏。

## 6. 最终设计目标

让碎言号成为一个具有高级编辑排版、优雅阅读体验和鲜明个人品牌的现代独立博客。

设计应当克制、耐看、清晰，并且经得起长期使用。
